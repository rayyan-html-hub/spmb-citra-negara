# Teks desain SPMB SMK Citra Negara (diekstrak dari docs/design.pdf)

File ini adalah versi TEKS dari PDF desain Figma, supaya bisa dibaca agent yang tidak bisa membuka PDF. Urutan teks per halaman mengikuti urutan elemen di desain. Halaman berlebar 1440 = desktop, berlebar 390 = mobile. Warna dan aturan visual ada di AGENTS.md (token: green #16A34A, side #15803D, dark #166534, light #DCFCE7, bg #F8FAFC, ink #0F172A, muted #64748B, line #E2E8F0; Inter; radius 16px; ikon Lucide).

Sumber kebenaran visual tetap docs/design.pdf: buka PDF itu langsung untuk tata letak, jarak, dan ukuran.
